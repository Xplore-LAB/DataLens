# DataLens：从曲线分析工具，到工艺运行复盘工作台

更新：2026-09-24。本文是产品经理作品集的事实底稿与下一步验证计划。当前已交付本地产品验证版，不是上线案例，不包含真实访谈、生产收益或模型性能的虚构数据。

## 产品定位与目标用户

**定位：帮助工艺工程师把一段运行数据整理成可定位、可核查、可跟进的复盘记录。**

主场景先落在脱硝运行复盘，原因是现有仓库已经有分钟级 NOx 与喷氨量示例、分析界面和配置。空分作为第二场景用于验证上下限语义，不能仅换变量名字就复用脱硝的节约判断。若真实数据与用户接触机会更集中在空分，应将主场景调整为空分；目前未获得这一确认。

- 使用者：工艺/运行工程师。触发时机：班次复盘、发现异常或准备优化讨论。
- 协作者：运行班长、仪控人员、工艺负责人。分别补充操作经过、仪表质量和工艺解释。
- 待验证的任务：从历史数据导出文件出发，定位值得讨论的时段，带着证据和问题与同事复核。
- 待验证的痛点：手工筛选曲线、对应时间与操作记录、截图和整理报告之间反复切换；“有指标裕量”容易被过早解读成“控制可减少”。
- 当前替代：Excel、已有历史数据库趋势图、人工截图和交接记录。新版的价值假设是缩短从数据到可复核记录的路径，不是替换现场控制系统。

上述工作流程与痛点是产品假设，尚未访谈验证。真实工业问题的依据是：SCR 性能与温度、还原剂使用、催化剂活性和氨逃逸等因素相关，仅靠出口指标与控制量不足以确认优化收益。参考 [EPA SCR 成本与技术章节](https://www.epa.gov/economic-and-cost-analysis-air-pollution-regulations/chapter-2-selective-catalytic-reduction) 与[技术手册](https://www.epa.gov/sites/production/files/2017-12/documents/scrcostmanualchapter7thedition_2016revisions2017.pdf)。这些材料支撑工艺因素复杂性，不证明本产品已有市场需求，也不作为中国现场的法规阈值来源。

## 从现有产品发现的核心问题

| 现状证据 | 用户风险 | 本次产品选择 |
| --- | --- | --- |
| 原 `index.html` 的 `computeWindow` 将低指标且控制量活跃的点按折扣减少控制量 | 观察共现被解释为可减少控制；没有验证减少后的过程响应 | 改为“待复核片段”，给出核查问题 |
| `drawBenefit` 将控制量采样值相加，并从观测跨度按 365 天外推 | 流量未按时间积分；阀位等量不能当消耗；短样本不代表全年 | 新版不输出节约量、年化收益或控制建议 |
| 原版统一使用小于触发线的判断，并显示“上限” | 氧纯度的下限要求可能被反向解释 | 明确约束方向，上限与下限分别判断 |
| 默认收益与预设参数和 NOx 耦合 | 改标签无法证明跨场景适用 | 显式配置口径，先支持观测复盘 |
| 脱硝示例配置有未转义双引号 | 示例 JSON 无法正常解析 | 修复配置语法并验证可解析 |

原版保留为历史分析工具，新增入口提示其收益仅为假设性估算；本次未重写原版所有分析。旧版输出不应作为生产结论。

## 本次交付：可实际操作的产品验证版

入口：运行 `node server/server.cjs` 后打开 `http://127.0.0.1:8767/review/`。规则示例无需账号、API Key 或外部模型；实时 Agent 需配置支持工具调用的模型服务。

首次体验：直接进入 DCS 风格历史复盘站，查看越界优先的事件索引 → 核对判定依据，点击片段引用 → 核对曲线和原始行 → 追问依据或缺失信息 → 导出摘要与完整复盘记录。

自主分析：导入 CSV → 确认字段、方向与阈值 → 运行分析 → 向复盘助手提出任务。配置模型后可切换实时 Agent；模型连接失败明确报错，不回退生成假结果。

已实现：

- 原始示例复用；导入 UTF-8 CSV，支持引号、字段映射，最多 5 MB / 20,000 条。
- 严格校验时间、空值和数值，显示无效行、重复时间与时间倒序；保留原始逻辑行号。
- 上下限分别判断；相等不计越界；逐点比较不替代正式合规判定。
- 持续时间按相邻样本左值保持估算，不把每行都当一分钟；不跨缺失/重复/较大间隔累计，最后一点不外推。
- 越界优先队列、图表定位、原始值、按片段类型生成的核查问题。
- 人工标记待复核/需跟进/已排除，记录现场补充，导出证据和口径。
- 参数或字段变化后暂停旧结果导出，重新分析后再使用；不同数据之间的人工结论不会混用。
- 首屏任务说明、免配置规则示例、证据引用跳转、三个可直接点击的追问、复盘摘要下载。
- 桌面与手机布局；规则统计本地计算。实时模型请求显式说明数据发送范围。
- 数据或口径变化后清空旧对话，终止未完成请求；工具执行记录与示例/实时模式一起保留到导出。

还未实现：真实历史库连接、Excel 导入、操作日志联查、多变量归因、账户与跨设备保存、团队协作。人工记录当前保留在页面内，应在离开前导出。

## Agent 的职责与实现边界

计数、排序、阈值判断和时间处理保留确定性计算；Agent 根据问题决定查看哪些片段、是否比较前后窗口、何时整理报告。模型每轮接收工具反馈后继续选择下一步，工具循环已实现于 `server/agent.cjs`。

已实现 5 个只读工具：`inspect_dataset`、`list_events`、`inspect_event`、`compare_event_windows`、`build_report`。后端重新计算上传数据，不信任前端传入的结论。最多 6 轮模型请求、16 次工具调用；模型没有检查数据、引用不存在或本轮未读取的片段时，拒绝输出该回答。

页面清楚区分两种模式：

- **示例讲解**：在当前数据上执行本地规则，支持检查、解释、缺失证据与摘要，不支持通用自由推理，不是模型回放。
- **实时 Agent**：连接兼容服务后实际调用模型。每个回答展示模型名称、已执行工具、参数、结果摘要和可点击的片段引用；不展示模型内部推理。

密钥仅在页面/进程内存使用，不写磁盘或日志。问题、历史对话和工具读取的数据会发送至配置的服务。工具不读取磁盘、不写生产系统、不控制设备。

当前的“前后对比”只是相邻样本的描述统计；没有操作日志、多变量匹配与对照条件，不能宣传为归因或因果识别。引用校验保证片段已读取，不保证模型自然语言中的每句话正确。

**验证状态：规则与工具循环通过自动测试，界面流程完成本地验证；尚无真实模型密钥，未完成供应商端到端调用及效果评测。** 不把模拟响应测试写成模型性能结果。

首轮访谈不问“你想不想用 AI”，请对方展示最近一次从数据到汇报的过程：哪些时间段难找、如何排除仪表问题、什么信息需要找同事、最终交付给谁、哪些错误不可接受。记录真实例子，不先推销功能。

主指标：完成一份被复核者接受的运行记录所需时间。质量指标：关键时段遗漏、无依据断言、错误排除异常、证据追溯成功率。使用指标：首次独立完成率、后续自愿复用。用户确认率或点击率不能代替分析正确率。所有业务数值目前留空，不写“节约 XX%”。

继续开发的条件：观察到可重复的流程痛点，并有用户愿意用自己的脱敏数据完成一次任务。若痛点只是报表排版，先做模板输出；若痛点是找日志，再做 Agent 检索，而非预先堆多 Agent。

## 作品集叙事与演示

推荐标题：**DataLens：把工业运行曲线转化为可核查的复盘记录**。

案例可按“原始工具 → 发现口径与流程问题 → 收敛目标用户 → 设计复核闭环 → 做出原型 → 验证数据处理 → 用户验证计划”展开。产品经理的贡献重点是定义问题、明确优先级、约束不可靠结论、设计人工反馈，而不是框架或工具数量。

90 秒演示：首页说明任务并点击体验（15 秒）→ 看到优先片段 E12，点引用核对第 177–180 行（25 秒）→ 追问为什么关注、还缺什么证据（25 秒）→ 导出摘要并展示实时 Agent 的连接入口与工具职责（25 秒）。示例使用默认口径；明确这是规则示例，实时效果尚待验证。

可如实使用的简历表述：

> 基于已有工业分析工具，设计并实现运行复盘工作台，串联 CSV 导入、数据质量检查、异常片段定位、人工复核与证据导出；区分上下限场景，纠正将指标裕量直接解释为节约收益的产品表达，完成本地数值和交互验证。

可补充“实现受限的只读工具调用 Agent 原型”，并注明尚待真实模型效果验证。只有完成用户验证后，才补充实测业务效果。

## 验证记录

- 15 个自动测试通过：6 项计算口径、3 项示例回答的数据依据与模式边界、6 项 Agent 工具循环/引用/取消/接口边界。模型测试使用注入的模拟响应。
- 仓库脱硝样例：241 条有效记录，6 个越界采样点、14 个裕量共现片段；这些只是默认口径下的软件输出。
- 仓库空分样例：11 条有效记录，默认下限 99.5 下为 11 个越界采样点。
- Chromium 本地验证通过：示例切换、下限判断、带批注导出、参数变化后暂停导出、重新分析、CSV 导入；1440 px 桌面和 390 px 手机布局无横向溢出，未记录到 JS 页面异常。
- 已检查桌面与手机截图。没有进行真实工厂、真实用户或模型效果验证。

- 新增上手与助手流程通过本地浏览器检查：一键示例、E12 证据定位、保持片段的追问、摘要生成与下载入口、未配置模型状态、连接失败提示、口径变化后暂停发送及导出。导入空分 CSV 后按下限 99.5 重新分析得到 11 个越界点；浏览器未记录到 JS 异常。

## 交互迭代：按工业复盘任务组织

入口使用重点时段清单，按越界优先展示片段编号、时间范围、类型、采样点数与估计时长，同时显示数据范围、设定约束与展示数量。默认定位首个重点片段，选择清单项时同步趋势高亮，不使用猜选、揭晓或分数反馈。宽屏补充统一纵轴尺度的局部趋势预览。

主曲线支持指针查询、点击片段和键盘可操作的时间游标；侧栏支持上一段/下一段、基于当前片段分析、加入跟进与撤销。进度仅表示定位、打开数据和跟进标记，不将其视作现场核查完成或异常闭环。颜色辅助区分类别，类型与状态始终有文本说明；取消卡片悬浮位移与答案入场动效。

这是面向工业历史数据的离线复盘原型，尚未对照工业 HMI 标准验证，也未接入实时告警或生产控制系统。

界面已按用户要求改为完整 DCS 风格操作站：固定导航和底部状态栏、历史读数面板、左侧全部事件索引、右侧趋势与数据视图；打开即加载示例，帮助页按需进入。设计来源与验证范围见 DESIGN-REFERENCE.md。

## 技术能力展示：从业务页面回到产品本身

顶栏新增“产品能力”工作台，保留 DCS 业务操作页，同时让面试官能验证 DataLens 的分析能力。

| 能力 | 可操作的展示 | 技术选择与边界 |
| --- | --- | --- |
| 数据适配 | 当前 CSV 列数、映射、原始与有效条数 | 浏览器解析，不依赖数据先上传模型；字段与阈值需确认 |
| 时序数据处理 | 无效行、重复行、倒序、代表间隔、间断、可累计时长 | 原始行号保留；缺失边界不积分，末点不外推 |
| 可解释分析 | 连续片段、越界点数与裕量复核片段数 | 数值由确定性引擎计算，模型不接管阈值与计数 |
| 参数敏感性 | 修改约束线，比较点数、片段数和估计时长 | 在当前数据上真实重算，使用独立试算对象，不覆盖复盘记录；并非工艺仿真 |
| Agent 工具循环 | 浏览器、本地服务、模型的职责图；最近一次执行轨迹 | 规则示例与实时调用明确区分，展示实际已完成步骤，真实模型效果仍待评测 |
| 结果一致性 | 数据与口径变动后旧结果失效 | 试算参数改动时清除旧试算输出；不会保留看似有效的陈旧比较 |

本次浏览器验证：上限 50→60 后越界采样点 6→0、片段 3→0，主工作台仍为上限 50；试算上限 40 与关注线冲突时显示错误并移除旧比较；规则示例生成 3 个真实本地步骤，并标明未调用模型。未修改核心分析引擎或后端模型调用逻辑。

作品集叙事应同时说明使用价值与工程取舍：为什么在本地计算、为什么保留原始行、如何处理缺失与不等间隔、为什么采用确定性工具而非让模型直接猜测数值、如何检验 Agent 是否比规则版更有增益。当前没有多变量归因、工艺仿真、收益优化算法或生产控制能力，不将它们作为已实现特性。
